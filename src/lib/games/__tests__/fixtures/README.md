# Scan photo fixtures

The photos are from Wikimedia Commons, shrunk to about 400 px and made
grayscale. `sudoku-angled-print.png` is the scan bench's `angled-blue-print.jpg`
cropped to its grid first, so its digits stay large enough to read. They are
PNGs without row filters, so a test can read them with `node:zlib` alone.
