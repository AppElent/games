# Scan photo fixtures

Both photos are from Wikimedia Commons, under
[CC BY 2.0](https://creativecommons.org/licenses/by/2.0/), shrunk to 400 px and
made grayscale. They are PNGs without row filters, so a test can read them with
`node:zlib` alone.
